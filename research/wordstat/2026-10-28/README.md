## Методика

- География: Россия `225`, Казахстан `159`.
- Частотности: GetTop за последние 30 дней. «Широкая» — исходная фраза; «фразовая» — фраза в кавычках, что фиксирует число слов; «точная» — кавычки и `!` перед каждым словом, что дополнительно фиксирует формы слов. Кавычки **не фиксируют порядок слов**.
- Устройства: `DEVICE_PHONE` и `DEVICE_DESKTOP` отдельно, только для широкой фразы. Планшеты не включены в колонку телефона.
- Динамика: GetDynamics по полным месяцам **октябрь 2025 — сентябрь 2026** для широкой фразы и трёх вариантов устройств (все, телефон, компьютер). Месячный метод поддерживает только оператор `+`, поэтому фразовую и точную динамику за 12 месяцев этим методом получить нельзя.
- «Что ещё ищут»: поле `associations` из широкого запроса. Оно может содержать тематически посторонние фразы, поэтому требует ручной фильтрации. Поле `results` содержит запросы с исходными словами.

По фразе «шк вб» широкий спрос намного больше фразового: часть запросов использует эти слова в других сочетаниях. Для SEO нельзя принимать 7 825 за спрос на одну конкретную формулировку. Запрос «генератор шк вб» заметно точнее: фразовая частота 292 из 629 широкой. За последние 12 полных месяцев его широкая месячная частота в РФ выросла с 389 (октябрь 2025) до 582 (сентябрь 2026); это сравнение двух месяцев, а не оценка тренда с поправкой на сезонность.

«Возвратная коробка ВБ» имеет 2 448 широких запросов, но только 8 фразовых и 5 точных. Основные уточнения относятся к операциям ПВЗ: недостачи, удаление, печать, хранение, создание и закрытие коробки. Это хороший кластер для FAQ или инструкции, но широкий показатель нельзя переносить на точную фразу. У «программа для ПВЗ ВБ» соотношение существенно чище: 135 широких, 46 фразовых и 45 точных. «Помощник ПВЗ» даёт 755 широких, но только 4 точных; выдача смешана с вакансиями и помощниками для Ozon, поэтому как основной SEO-запрос он слабее.

Кластер функции поиска клиента оказался низкочастотным в заданных формулировках. «Код клиента ПВЗ» имеет 307 широких запросов, но API не вернул частотность для фразового и точного соответствия. «Код клиента по ячейке» и «подбор кода ПВЗ» получили по 2 широких запроса, «узнать код получения ВБ» — 7, «досье клиента ПВЗ» — без частотности. Это не подтверждает отдельный SEO-лендинг `/kod-klienta-pvz` на основании текущих формулировок; перед решением стоит проверить более естественные варианты «код клиента ВБ», «найти клиента по ячейке» и «поиск клиента ПВЗ».

«Отзывы ПВЗ» показывает 17 738 широких запросов, но лишь 23 фразовых и 16 точных. Содержащие запросы относятся к отзывам о ПВЗ Ozon, Wildberries и Яндекс Маркета, открытию ПВЗ, работе и отзывам владельцев. Для функции досье это слишком общий и неоднозначный основной запрос.

## Вывод для страниц

Текущие данные поддерживают формулировку «генератор ШК ВБ» на странице генератора и вопрос «Что такое ШК на ВБ?» в FAQ, если содержание страницы действительно отвечает на них. Для страницы программы полезна точная формулировка «программа для ПВЗ ВБ»; более общий «помощник ПВЗ» лучше использовать как дополнительную лексику, а не основной Title/H1. Самостоятельные лендинги под «стикеры ВБ 58×40» и `/kod-klienta-pvz` пока не подтверждены исходными формулировками. Для `/pechat-nomera-yacheyki` есть небольшой целевой кластер, но основной широкий запрос неоднозначен; страницу разумнее позиционировать как «печать номеров ячеек для ПВЗ Wildberries» и раскрыть программу, автоматическую печать и выбор принтера. Запрос «открыть ПВЗ ВБ» достаточно крупный для отдельной информационной статьи или руководства, если сайт готов полноценно ответить на намерение открытия пункта; использовать его на странице автоматизации сети не следует. Title, H1 и новые лендинги не менялись.

## Возобновление

Сборщик [collect-wordstat.mjs](../../../tools/collect-wordstat.mjs) использует только переменные окружения `YANDEX_SEARCH_API_KEY` и `YANDEX_SEARCH_FOLDER_ID`; ключа в репозитории нет. Он сохраняет успешные ответы и повторно их не запрашивает. Текущий набор завершён; повторный запуск не выполнит новых запросов, пока список фраз или параметры не изменятся. После изменения списка запускать `node tools/collect-wordstat.mjs`, затем `node tools/summarize-wordstat.mjs`. По умолчанию за запуск выполняется не более 90 новых запросов, чтобы оставить запас часовой квоты.
