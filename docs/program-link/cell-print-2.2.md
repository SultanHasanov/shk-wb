# «Печать ячеек» 2.2 — связка с аккаунтом (спецификация для программы)

Патч **не применяется** здесь: исходники программы живут в `_local-only/cell-print-tauri/`
(вне этого репозитория). Этот файл — точная спецификация для реализации на стороне программы;
`.patch` генерируется против исходников Tauri отдельно. Серверная часть уже готова и покрыта тестами.

## Задача
Чтобы после входа аккаунтом сайта программа сама подхватывала/активировала подходящую лицензию
«Печати ячеек» без ручного ввода ключа, и чтобы отключение ПК в кабинете работало.

## Что добавить в программу

### 1. deviceHash при входе и refresh
При `login`, `login/start`, `login/poll`, `refresh` слать в теле:
```json
{ "deviceHash": "<sha256(MachineGuid), 64 hex>", "deviceName": "<имя ПК>", "appVersion": "2.2.0" }
```
`deviceHash` считается так же, как `X-Device-Id` (sha256 от MachineGuid). Старые версии его не слали —
сервер это допускает. На ответ `401 { code: "DEVICE_REVOKED" }` показать экран входа и сообщение
«Этот компьютер отключён в кабинете».

### 2. Автопривязка после входа
Сразу после успешного входа (и при старте, если есть сессия и ещё нет активной лицензии на этом ПК)
вызвать:
```
POST /api/cell-print/account/link
Authorization: Bearer <access_token>
{ "deviceHash": "...", "deviceName": "...", "appVersion": "2.2.0",
  "key": "<опц. локально сохранённый ключ>", "legacyHash": "<опц. старый отпечаток>" }
```
Ответы:
- `{ "status": "linked", "key, scope, expiresAt, deviceLimit, devicesUsed" }` — всё, лицензия активна.
- `{ "status": "choose", "options": [{ "key", "label": "CP-••••-••••-ZZZZ", "scope", "expiresAt", "devicesUsed", "deviceLimit" }] }`
  — показать список (label для показа), по выбору повторить `link` с `key` выбранного.
- `{ "status": "full", "buyUrl" }` — все ключи заняты; кнопка «Купить/докупить» на `buyUrl`.
- `{ "status": "none", "buyUrl" }` — у аккаунта нет ключей; кнопка «Купить» на `buyUrl`.
- Ошибки: `403 KEY_OWNED` (чужой ключ), `403 ACCOUNT_REQUIRED` (замок), `403 KEY_EXPIRED`,
  `409 DEVICE_LIMIT`, `404 KEY_NOT_FOUND`, `401 DEVICE_REVOKED`, `426 UPDATE_REQUIRED`.

Если `link` вернул `linked`, обычный `activate` по ключу больше звать не нужно (link уже активировал).
Можно оставить и ручной ввод ключа как запасной путь (существующий `activate` не изменился).

### 3. Версия
Отправлять `appVersion` ≥ `2.2.0`; ниже `1.5.0` сервер вернёт `426`.

## Что НЕ меняется
Анонимная активация по ключу (`POST /api/cell-print/activate`) работает как раньше — для тех, кто не входит.
