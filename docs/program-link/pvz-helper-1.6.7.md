# «Помощник ПВЗ» 1.6.7 — автопривязка пакета подборов (спецификация)

Патч **не применяется** здесь: исходники в `_local-only/pvz-tauri/` (вне репозитория).
Серверная часть (`/api/app/claim-key`) уже существует — нужен только вызов из программы.

## Задача
После входа аккаунтом сайта автоматически привязать к аккаунту локально сохранённый ключ WBPK
(остаток «Подбора кодов» / пакет подборов), чтобы пользователь не вводил его руками.

## Что добавить в программу
После успешного входа, если в конфиге есть локальный ключ WBPK и он ещё не отмечен привязанным:
```
POST /api/app/claim-key
Authorization: Bearer <access_token>
{ "key": "<WBPK-ключ>" }
```
- Успех → поставить локальную отметку `wbpk_claimed = true` (больше не повторять).
- `409`/ключ уже за другим аккаунтом → тоже отметить обработанным (повтор бессмыслен), показать мягкую подсказку.
- Сетевая ошибка → повторить при следующем входе.

Это «Помощника» касается только привязки существующего ключа; тарифы/лимиты приходят в `/api/app/me` как сейчас.

## Что НЕ меняется
Вход, аренда (`/lease`), обновления, списание генераций — без изменений. Старые версии 1.6.x работают как есть.
