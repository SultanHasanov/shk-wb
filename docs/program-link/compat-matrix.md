версий продолжает работать без изменений. Сводка «версия × эндпоинт» до и после.

## Поведение БД

- `activate_cell_print_license(p_key, p_device_hash, p_legacy_hash := null, p_user := null, p_device_name := null)`:
  старые вызовы (3 именованных аргумента через PostgREST) резолвятся на новую сигнатуру — PostgREST
  подбирает функцию по переданным именам, лишние параметры берут значения по умолчанию.
- Лимит устройств теперь считает **только не отозванные** активации (`revoked_at is null`).
- Мягкий отзыв (`cell_print_revoke_device`) освобождает место, но не удаляет историю.
- Замок `require_account` (по умолчанию `false`) блокирует **только новые** ПК; уже активные работают и без входа.
