# Локальная проверка редизайна (ветка `site-redesign`)

Эта ветка живёт в отдельной папке-worktree `../shk-wb-redesign` (ветка `site-redesign`,
отведена от последнего коммита `main` `c1c36ba4`). Основная папка `../шк-вб` с
незакоммиченной работой по «Печати ячеек» 2.x **не трогается**.

## ⚠️ Главное: локальный запуск пишет в БОЕВУЮ базу

`.env.local` содержит боевой `SUPABASE_SECRET_KEY`. Любой локальный запуск
`selfhost/server.cjs` или тестов, которые реально ходят в Supabase, работает с
**продакшен-данными**. Поэтому:

- Любые проверки входа/привязки ключей/активаций — **только на выделенных тестовых
  аккаунтах и тестовых ключах**. Не трогать реальные ключи и подписки клиентов.
- **Никогда** локально не запускать: cron (`/api/cron/*`), вывод реферальных
  (`referrals/withdraw`), массовые рассылки, удаление аккаунта.
- Ключи YooKassa локально отсутствуют → создать реальную оплату нельзя (это хорошо).
- Миграции БД применять **только на PGlite** до слияния. Боевую схему меняем лишь при
  выкладке, по отдельной команде владельца.

## Защита от случайного деплоя (Фаза 0)

- `.github/workflows/deploy.yml`: job деплоя идёт `if: github.ref == 'refs/heads/main'`
  — ручной запуск (`workflow_dispatch`) с ветки `site-redesign` на прод не выкатит.
- `selfhost/deploy.sh`: отказывается работать, если ветка не `main` или дерево грязное
  (осознанный обход — `ALLOW_NON_MAIN=1`).
- `vercel.json`: `git.deploymentEnabled.site-redesign=false` — превью Vercel для ветки
  отключено (если интеграция ещё жива). Деплой на shk-wb.ru идёт только через GitHub
  Actions из `main`, Vercel их production-путём не является.
- `.gitignore`: `/*.csv` — выгрузки WB с ПДн не попадут в коммит.

**Пуш ветки `site-redesign` в origin безопасен** — Action не запустится (только `main`).
Но не запускать `deploy.sh` из этой папки без причины и не делать `workflow_dispatch`.

## Как запускать

```bash
# из папки worktree
npm ci                      # уже сделано при создании ветки
npm test                    # vitest run — все тесты
npm run build               # tsc -b + vite + пререндер (нужен Chromium)
npx playwright install chromium   # один раз, для пререндера
```

Для просмотра собранного сайта локально: `node selfhost/server.cjs` (отдаёт `dist` +
проксирует `api/`). Перед этим — `npm run build`.

## Чего НЕ делать в основной папке `../шк-вб`

Никаких `git add -A`, `git stash`, `git checkout` — там лежит незакоммиченная работа
владельца и gitignored-исходники программ. Все изменения редизайна — только в этой папке.
